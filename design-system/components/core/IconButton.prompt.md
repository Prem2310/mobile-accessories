One-line: round icon-only button for header actions (search, wishlist, cart) and card overlays.

```jsx
<IconButton label="Wishlist" tone="brand"><Icon name="heart" /></IconButton>
<IconButton label="Menu" tone="onDark"><Icon name="menu" /></IconButton>
```

Tones: neutral (light surfaces), brand (orange wash), onDark (navy bars). Never smaller than 34px; 44px default.
